# Portfolio Piero actualizado

Incluye foto personal y seis certificados con miniaturas y PDF.

1. Copia src, public e index.html dentro de tu proyecto Portfolio-Piero y acepta reemplazar archivos.
2. Conserva tu package.json y la carpeta .git.
3. Si aún no instalaste los iconos: npm install devicon@2.17.0
4. Ejecuta npm run dev.

Edita tus datos, proyectos y certificados en src/data/portfolio.js.
